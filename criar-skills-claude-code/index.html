Guia prático

Como criar uma skill no Claude Code

Transforme um procedimento que você repete em instruções que Claude Code pode consultar quando forem úteis.

Conteúdo conferido em 27 de setembro de 2026.

Uma skill começa com uma pasta e um arquivo SKILL.md. Nele você explica o que a skill faz, quando ela deve ser usada e quais passos seguir. Scripts, referências e modelos são opcionais: inclua-os somente se ajudarem o fluxo.

1. Escolha um trabalho repetido

Comece por uma tarefa concreta, como organizar notas em resumo, decisões e próximos passos. Uma skill focada em um trabalho tende a ser mais fácil de entender e ajustar do que uma que tenta resolver várias coisas diferentes.

2. Crie a pasta e o arquivo

Para disponibilizar a skill apenas em um projeto, crie uma pasta em .claude/skills/ dentro do repositório. A estrutura mínima fica assim:

.claude/
└── skills/
    └── resumir-notas/
        └── SKILL.md

3. Escreva os metadados e as instruções

O arquivo começa com metadados YAML entre duas linhas com três hífens. Use uma descrição que diga claramente quando Claude deve escolher essa skill. Depois, escreva os passos em Markdown.

---
name: resumir-notas
description: Organiza notas fornecidas pelo usuário em resumo, decisões e tarefas. Use quando pedirem para estruturar notas de reunião.
---

# Organizar notas

1. Leia todas as notas fornecidas.
2. Separe resumo, decisões e tarefas.
3. Não invente participantes, prazos ou decisões ausentes.
4. Marque como "não informado" o que estiver faltando.

4. Teste e melhore

Abra Claude Code no projeto e faça um pedido que deveria acionar a skill. Confira se ela foi selecionada e se as instruções produziram o formato esperado. Teste também um pedido parecido que não deveria acioná-la. Ajuste a descrição se ela for acionada em situações erradas ou não for encontrada quando necessária.

Se a tarefa exigir arquivos de referência ou scripts, organize-os em subpastas e explique no SKILL.md quando devem ser usados. Antes de executar código vindo de terceiros, revise o que ele faz.
