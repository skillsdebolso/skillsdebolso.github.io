Como instalar skills no Claude Code

Veja onde salvar uma skill para usar só em um projeto ou em vários projetos seus.

Conteúdo conferido em 27 de setembro de 2026.

Uma skill do Claude Code é uma pasta que contém um arquivo SKILL.md. O local dessa pasta determina onde ela poderá ser usada. Este guia explica como organizar uma skill que você já tenha; a Skills de Bolso ainda não oferece packs para baixar.

Escolha onde a skill deve funcionar

  • Em um projeto: coloque a pasta dentro de .claude/skills/ no repositório. Assim, a skill pode ser compartilhada com o time quando os arquivos forem versionados.
  • Nos seus projetos locais: use a pasta pessoal ~/.claude/skills/. Ela fica na pasta de usuário do seu computador e não é compartilhada automaticamente com o repositório.
  • Skill de plugin ou sincronizada: siga o método próprio do plugin ou da conta Claude. Não copie esses arquivos para outra pasta sem conferir como a fonte os atualiza.

Passo a passo para uma skill local

  1. Obtenha os arquivos de uma fonte em que você confia. Confira a licença e leia as instruções antes de executar scripts.
  2. Abra a pasta do projeto ou a pasta pessoal do Claude Code, conforme o alcance desejado.
  3. Dentro de .claude/skills/ (ou ~/.claude/skills/), crie uma pasta própria para a skill.
  4. Coloque o arquivo SKILL.md diretamente dentro dela. Arquivos de apoio podem ficar em subpastas.
  5. Confira se a estrutura ficou parecida com o exemplo abaixo.
.claude/
└── skills/
    └── minha-skill/
        └── SKILL.md

Como conferir se foi carregada

Abra o Claude Code no projeto correspondente e consulte a lista de skills com /skills. Se acabou de criar a pasta e a skill não aparecer, use /reload-skills ou inicie uma nova sessão. Recursos e nomes de comandos podem mudar; confira a documentação oficial para a versão instalada.

A pasta correta depende de onde você quer usar a skill. Para um fluxo pessoal, escolha a pasta do usuário; para um fluxo compartilhado com o projeto, escolha .claude/skills/ dentro do repositório.
