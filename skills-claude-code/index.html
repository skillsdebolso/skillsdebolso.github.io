O que são skills no Claude Code?

Skills são instruções reutilizáveis que ajudam Claude Code a seguir um jeito definido de fazer tarefas que se repetem.

Conteúdo conferido em 27 de setembro de 2026.

Uma skill reúne instruções em um arquivo chamado SKILL.md. Ela pode também ter arquivos de apoio e scripts. Claude Code pode carregá-la quando o pedido combina com o que ela faz; dependendo da configuração, também é possível chamá-la pelo nome, como um comando.

Em vez de repetir a mesma lista de orientações a cada conversa, você pode guardar o passo a passo em uma skill. Por exemplo, uma equipe poderia documentar como revisar uma alteração de código. O exemplo é ilustrativo: a skill só fará o que as instruções e ferramentas disponíveis permitirem.

Quando vale criar uma skill?

Uma skill pode ser útil quando você repete um fluxo com frequência, precisa seguir uma checklist ou quer compartilhar instruções de trabalho com outras pessoas do projeto. Se a informação é um fato que deve estar sempre presente, a documentação do projeto pode ser mais adequada; a skill é voltada a um procedimento que Claude usa quando for pertinente.

Como uma skill se organiza?

O formato básico é uma pasta com um SKILL.md. Esse arquivo contém metadados em YAML e as instruções em Markdown. Pastas de apoio são opcionais e só devem ser adicionadas quando ajudam o fluxo.

minha-skill/
└── SKILL.md

Claude Code permite skills pessoais, de projeto e vindas de plugins. Uma skill de projeto pode ser versionada junto com o repositório; uma skill pessoal fica disponível nos projetos daquele usuário. A escolha depende de quem precisa usar as instruções.

O que skills não fazem sozinhas

Uma skill não é um modelo novo nem garante que uma tarefa será concluída corretamente. Ela orienta o agente; o acesso a arquivos, comandos e ferramentas depende do ambiente e das permissões configuradas. Leia e revise skills de terceiros antes de usá-las, especialmente quando incluem scripts.
